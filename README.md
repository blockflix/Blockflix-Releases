# Blockflix Desktop Releases

This public repository hosts official Blockflix Desktop installer artifacts and
Tauri update manifests only. The Blockflix source code is private and is not
licensed for copying, modification, redistribution, or derivative works.

## Downloads

- macOS Apple Silicon: `Blockflix_<version>_macos_aarch64.dmg`
- macOS Intel: `Blockflix_<version>_macos_x64.dmg`
- Windows x64: `Blockflix_<version>_windows_x64-setup.exe` or `.msi`
- Linux Debian/Ubuntu: `Blockflix_<version>_linux_amd64.deb`
- Linux Fedora/RHEL: `Blockflix_<version>_linux_amd64.rpm`

The Desktop updater reads:

```text
https://github.com/blockflix/desktop-releases/releases/latest/download/latest.json
```
